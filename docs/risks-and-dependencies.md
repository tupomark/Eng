# Зависимости и риски

## Технологические зависимости

| Зависимость                         | Назначение                                        | Статус первого этапа                                                            |
| ----------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------- |
| Node.js и npm                       | Установка, сборка, локальный запуск               | Версия должна удовлетворять `engines` выбранного Next.js                        |
| Next.js / React / TypeScript        | Маршруты и типизированный интерфейс               | Основа приложения, точные версии фиксируются в package.json и lockfile          |
| Tailwind CSS                        | Токены и адаптивные стили                         | Основа визуальной реализации                                                    |
| Vitest                              | Детерминированные unit-тесты                      | Проверка модели знаний и storage                                                |
| PGlite                              | Локальный PostgreSQL-движок для проверки миграции | Не является подключением Supabase                                               |
| Playwright                          | Сценарий пользователя и мобильная вёрстка         | Требует установленных браузеров; WebKit не заменяет физический iPhone           |
| Supabase / PostgreSQL               | Будущие Auth и постоянное серверное хранение      | Схема готовится локально; живое подключение отсутствует до настройки и проверки |
| GitHub / Vercel                     | Будущие source hosting, CI и deployment           | Внешние ресурсы не считаются созданными автоматически                           |
| Motion / Rive                       | Дополнительная анимация при необходимости         | Не требуются для первого сценария; подключать по обоснованию                    |
| AI / STT / TTS / словарный источник | Будущие оценки, речь и лексические данные         | Выбор провайдеров и действующие credentials ещё нужны                           |

Не устанавливать библиотеку только потому, что она входит в предпочтительный стек. Версии и наличие зависимости проверяются в lockfile. Провайдерские SDK должны оставаться за адаптерами. Новая зависимость оценивается по API, лицензии, размеру клиентского bundle и совместимости с целевыми платформами.

## Основные риски

| Риск                                              | Последствие                                              | Решение и проверка                                                                                                                                                                                                               |
| ------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Локальный storage очищен, запрещён или переполнен | Потеря истории либо ложное сообщение об успехе           | Явный статус локального режима; обработка ошибок; runtime-валидация; перед облачным пилотом экспорт/перенос и резервное копирование                                                                                              |
| Конкурирующие записи вкладок и устройств          | Потеря наблюдений или дубли                              | Browser repository проверяет устаревший snapshot и слушает storage events, но localStorage не даёт атомарной межвкладочной compare-and-swap; перед синхронизацией нужны транзакции, event ID, стратегия merge и тесты конфликтов |
| Уязвимость XSS                                    | Доступ к локальной истории                               | Не вставлять непроверенный HTML, не хранить секреты и приватные книги по умолчанию; production CSP и аудит внешнего контента                                                                                                     |
| Смешение слова и значения                         | Неверная оценка знания многозначных слов                 | Отдельные stable sense ID, проверки выбора значения и ограничений модели                                                                                                                                                         |
| Перенос самооценки на другие навыки               | Ложное ощущение прогресса                                | Изоляция навыков в domain и тестах; неизмеренные навыки показываются явно                                                                                                                                                        |
| Некалиброванное расписание                        | Неоптимальная частота повторений                         | Версионированная понятная эвристика; не называть её научно валидированной моделью; последующая оценка на реальных данных                                                                                                         |
| Ошибочная AI-оценка                               | Недоверие и неверные рекомендации                        | Объяснение, provenance, версия rubric, оспаривание и replay; калибровочные наборы до подключения                                                                                                                                 |
| Ограничения словарных лицензий                    | Запрет хранения, озвучки или коммерческого использования | На первом этапе авторские данные; перед интеграцией проверить условия примеров, IPA, аудио, cache и attribution                                                                                                                  |
| Персональные тексты и аудио                       | Избыточное хранение чувствительных материалов            | Минимальные выдержки; raw audio не хранится по умолчанию; явные сроки retention, consent и удаление до voice-пилота                                                                                                              |
| Ошибка Auth/RLS или межпользовательская ссылка    | Утечка пользовательских данных                           | RLS на exposed tables, ownership checks, composite FK, реальные JWT-тесты двух пользователей перед серверным пилотом                                                                                                             |
| Стекло и эффекты на iPhone                        | Падение FPS, нагрев, снижение читаемости                 | Статическая глубина, ограниченный backdrop-filter, transform/opacity, Reduced Motion; проверка физического устройства                                                                                                            |
| Нет финального визуального утверждения            | Расхождение ожиданий по эстетике                         | Получены и просмотрены пять отобранных референсов; точные токены и финальный UI требуют визуальной проверки, письменный brief имеет приоритет                                                                                    |
| Стоимость и лимиты внешних API                    | Непредсказуемые задержки и расходы                       | Серверные лимиты, timeout, budget, контролируемый retry и fallback после выбора провайдера                                                                                                                                       |
| Изменение API и security advisories               | Сбой интеграции или уязвимости                           | Актуальная документация, точные версии, lockfile, проверяемые обновления и CI                                                                                                                                                    |

## Что нужно для настоящих интеграций

Для Supabase нужны согласованный проект, способ входа, окружения разработки/теста, правила session handling и доступ для проверки миграций. Ключ service role не передаётся клиенту. Для AI необходимы выбранный провайдер, бюджет, критерии оценки и условия использования учебных материалов. Для речи — поддерживаемые языки/акценты, политика микрофона, STT/TTS-провайдер и решение о хранении аудио. Для словаря — лицензия и документированный API.

Наличие SDK, интерфейса адаптера или env placeholder не подтверждает работающую интеграцию. Подключение считается выполненным только после реального запроса, проверки результата, сценария ошибки и отражения ограничений в продукте.

## Пределы локальной проверки

Unit-тесты подтверждают описанные правила и граничные случаи, SQL-тесты — выполнение миграции и ограничения в тестовой среде, Playwright — конкретные браузерные сценарии. Они не доказывают качество обучения, пригодность AI-оценки, безопасность будущей инфраструктуры или производительность на всех iPhone. Перед пилотом каждая такая гипотеза получает собственную проверку.
