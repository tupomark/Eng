# Трассируемость требований LEXIS

Дата baseline: 22 октября 2026, до изменений новой итерации. После проверки строка должна ссылаться на фактический тест, снимок и запись PROGRESS. `local` означает работающую ограниченную возможность в браузере; `partial` — часть модуля; `prototype` — явно обозначенный визуальный сценарий; `planned` — реализации нет. Ни один статус сам по себе не подтверждает удалённую интеграцию или завершённый модуль.

## Проверка статуса

Функция считается проверенной только при совпадении её scope, фактического результата и evidence. Демонстрация Voice listening state не подтверждает запись звука; SQL-файл не подтверждает cloud DB; AI port не подтверждает AI; FSRS-направление не превращает heuristic-v1 в FSRS. Дата baseline и последующие записи позволяют сохранять историю без ложного впечатления завершённости.
