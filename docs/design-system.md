# Дизайн-система LEXIS

## Основа и статус

Согласованное направление: премиальная минималистичная среда из графита, глубокого espresso, тёплого песка и сдержанной бронзы. Матовые поверхности и мягкие скульптурные формы создают глубину; типографика и свободное пространство обеспечивают читаемость.

Исходные Figma-макеты, изображения или ссылки на визуальные эталоны не были предоставлены. Они запрошены. Начальная реализация — предварительная интерпретация письменного brief, без утверждения о точном совпадении с референсом. Коррекция после получения референсов должна сохранять утверждённое направление и обсуждаться, если меняет его.

## Уровни токенов

Первичные токены задают палитру и размеры. Семантические токены описывают назначение: фон, основной текст, вторичный текст, поверхность, граница, фокус. Компоненты используют семантические значения, чтобы изменение оттенка не требовало правок каждого экрана.

| Группа         | Начальное направление                              | Правило использования                                      |
| -------------- | -------------------------------------------------- | ---------------------------------------------------------- |
| Canvas         | Тёплый графит `#22211e`, espresso `#1b1a17`        | Спокойный общий фон без движущихся градиентов              |
| Surface        | Тёплый тёмный серый; ограниченная прозрачность     | Достаточная непрозрачность для предсказуемой читаемости    |
| Text primary   | Светлый песок `#f0e9dc`                            | Основной текст, достаточная плотность шрифта               |
| Text secondary | Приглушённый бежевый `#b6afa2`                     | Подписи, не критичные для основного действия               |
| Accent         | Песок `#d7c3a2`, сдержанная бронза `#b49a72`       | Выбор значения, активная навигация, важные действия        |
| Border         | Тёплый светлый оттенок с низкой непрозрачностью    | Разделение поверхности, без множества рамок                |
| Radius         | Небольшие элементы 12–16 px; поверхности 24–32 px  | Согласованные мягкие формы                                 |
| Space          | Шаг 4 px; основные интервалы 8/12/16/24/32/48      | На мобильном не уменьшать расстояния до тесноты            |
| Motion         | 160–240 ms для управления; медленное дыхание сферы | Анимация показывает состояние и подчиняется Reduced Motion |

Цвета в таблице соответствуют текущим CSS-токенам приложения. Остальные значения задают правила развития компонентов. Контраст нужно проверять на фактических составных фонах: обычный текст минимум 4.5:1, крупный 3:1; границы интерактивных элементов и focus — 3:1 там, где они необходимы для распознавания. Полупрозрачность не является поводом снижать контраст; эта спецификация сама по себе не подтверждает прохождение contrast audit.

## Типографика

Основа — современный системный sans-serif с качественным отображением кириллицы и латиницы; загрузка внешнего шрифта не должна блокировать чтение. Основной текст использует обычное или среднее начертание. В Reader допускается литературный serif системного стека с комфортным межстрочным интервалом и ограничением длины строки.

Заголовки, подписи и значения статистики образуют ясную шкалу. Нельзя использовать чрезмерно тонкое начертание или уменьшать полезный текст ради декоративной композиции. iPhone input имеет размер не менее 16 px, чтобы избежать неожиданного zoom Safari.

## Компоненты

```text
Foundations
  Color / Type / Space / Radius / Elevation / Motion
Primitives
  Button / IconButton / Surface / Input / Badge / Progress / EmptyState
Patterns
  Navigation / AccessibleDialog / Command / DictionarySheet / ReviewCard
Workspaces
  Home / Reader / SmartReview / Core / VoiceAssistant
```

`Surface` имеет несколько осмысленных уровней глубины. Стекло применяется к навигации и отдельным плавающим панелям; текст не размещается поверх непредсказуемой декоративной картинки. Много вложенных карточек не должно заменять информационную иерархию.

`DictionarySheet` показывает слово, выбранное значение, пример, контекст и одно главное действие сохранения. Разные значения различимы без знания их технических ID. Сохранённое состояние явно обозначено. `ReviewCard` отделяет вопрос от раскрытого ответа, затем показывает самооценку и результат расписания.

## Home и Living Core

Home строится вокруг продолжения обучения. Living Core — один выразительный спокойный объект и несколько понятных показателей реальных данных. Он не превращается в сеть из десятков узлов. Если истории ещё нет, Core приглашает создать первое наблюдение; декоративная форма не изображает вымышленный уровень владения.

Рекомендация первого этапа основана на доступных данных: продолжить текст или повторить сохранённое значение. Она не подписывается как AI-рекомендация без работающего AI.

## Voice Assistant

Ключевой образ — полупрозрачная матовая сфера с мягким бронзовым светом и лаконичным символом микрофона. Глубину создают статические слои, границы и мягкие тени. Допустимы умеренные transform/opacity-анимации; анимировать крупный blur или запускать WebGL ради прототипа не требуется.

Визуальный прототип должен прямо сообщать об отсутствии голосового подключения. Декоративная анимация не отображает реальный уровень микрофона и не должна подразумевать, что пользователь записывается. Настоящий capture в будущем требует явного действия, доступного индикатора состояния и контролируемой остановки.

## Адаптивность и доступность

- iPhone: одна колонка, нижняя навигация, `env(safe-area-inset-bottom)`, минимальная зона нажатия 44×44 px. Высота workspace использует динамический viewport с запасным вариантом.
- Широкий экран: спокойная боковая навигация, ограниченная ширина чтения, больше пространства между смысловыми группами.
- Reader и Voice: полноэкранный workspace с видимым выходом. Открытые панели учитывают экранную клавиатуру и прокрутку.
- Диалоги: доступное имя, начальный focus, удержание focus, Escape, возврат focus после закрытия. Состояния сохранения доступны скринридеру.
- Выбор слова возможен с клавиатуры и нажатием; hover не является единственным способом доступа.
- `prefers-reduced-motion` отключает дыхание сферы и необязательные перемещения. Смысл и доступность действий сохраняются.

## Проверка визуального качества

Проверять Home, Reader, выбор значения, Review и Voice при ширине 390 px и на широком экране. Отдельно проверять длинные определения, русский текст, масштабирование текста, отсутствие горизонтального скролла, видимый focus и режим Reduced Motion. Автоматизированный WebKit полезен, но финальная проверка динамических панелей и производительности на физическом iPhone Safari остаётся отдельным критерием.
