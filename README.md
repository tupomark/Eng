# LEXIS

Персональная среда для изучения английского: значения слов, контекст и независимые свидетельства по пяти навыкам.

## Запуск

Требуется Node.js 22.18+ (проверено на 24.19) и npm. Внешние сервисы и `.env` для этого этапа не нужны.

```sh
cd /workspace/lexis
npm ci
npm run dev
```

Откройте `http://localhost:3000` на машине, где запущен сервер. Для production-режима: `npm run build`, затем `npm start`. В этой среде используются Webpack-команды: внутренний процесс Turbopack ограничен sandbox.

## Что работает

- Home с реальными локальными показателями; Library, Learn, Core и полноэкранный Reader.
- Авторский текст из трёх частей; выбор слова нажатием, клавиатурой и выделением; честное пустое состояние неизвестного слова.
- Редакционный словарь восьми слов с транскрипцией, переводами, примерами, сочетаниями и несколькими значениями у `linger` и `trace`.
- Выбор и сохранение конкретного значения вместе с предложением; защита от дублей и сохранение позиции чтения после reload.
- Smart Review: раскрытие значения, самооценка recognition, проверяемый алгоритм расписания `heuristic-v1`, следующая дата повторения.
- Core: раздельные сигналы пяти навыков, объяснение оценок и оспаривание с пересчётом истории.
- LEXIS Command: поиск разделов и локальных слов, вызов кнопкой или ⌘/Ctrl+K.
- Проверка версии и содержимого localStorage, сохранение повреждённых данных без перезаписи, экспорт JSON, явное подтверждение сброса. Ошибки записи не выдают сообщение об успехе.
- SQL-миграция для Supabase/PostgreSQL с RLS и тестами изоляции двух пользователей на PGlite.

## Границы этапа

Данные находятся **только в этом браузере**. Нет аккаунта, синхронизации и резервного копирования в облако. JSON-экспорт не является обещанием доступного импорта: импорт восстановления пока не реализован. Защита от устаревшего состояния вкладки снижает риск перезаписи; localStorage не даёт транзакционной изоляции при строго одновременных записях.

UI не обращается к Supabase: миграция подготовлена и проверяется отдельно. Auth, удалённый repository, серверная транзакция и projector — обязательный следующий срез перед многопользовательским пилотом. AI, лицензированный словарь, TTS/STT, микрофон, GitHub remote и Vercel не подключены. Voice Assistant — обозначенный визуальный прототип без записи звука; Permissions-Policy запрещает microphone/camera.

Оценки выводятся из самоотчётов пользователя. Они не измеряют реальное владение языком, а текущий планировщик не является FSRS. Сохранение слова не увеличивает оценки; recognition не повышает writing/speaking.

Визуальная система следует письменному brief: graphite/espresso, sand/bronze, мягкие матовые поверхности. Исходные референсы запрошены; точность относительно оригинальных макетов не подтверждена.

## Проверки

```sh
npm run typecheck
npm test
npm run build
PLAYWRIGHT_BROWSERS_PATH=.cache/ms-playwright npx playwright install --with-deps chromium webkit
npm run test:e2e
```

Playwright сам запускает production-сервер; build должен быть создан заранее. На Linux с `/usr/bin/chromium` используется системный Chromium; путь можно явно задать через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. WebKit загружается в игнорируемую `.cache/ms-playwright`; системные зависимости устанавливаются только в вашей обычной dev/CI-среде. В ограниченной среде могут потребоваться дополнительные права для локального сервера и браузеров. Эмуляция iPhone/WebKit не заменяет проверку на физическом iPhone Safari.
